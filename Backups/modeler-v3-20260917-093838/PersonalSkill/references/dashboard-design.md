# Philips modeler design and user journey

Controlling design: AOP2027-IT-Portfolio-Scenario-Modelling.html in `Documents/Codex/2026-09-15/create-an-image-of-2/outputs`. Preserve its compact Philips header, blue controls, tabs, Frutiger/Calibri local font stack, white panels, grouped table and status colours. Primary #0B5ED7; dark #00126E; light #BDF0FF; background #FAFBFC; border #D5DAE0. Screenshots are layout references, not authority for old CCB, waste, decommissioning or ROI-pool rules.

Exactly four tabs in order: AOP Scenarios, Enterprise Wide, BU Led, AOP2027 : Overview. The order supports a natural review flow, but Enterprise Wide and BU Led have no completion, validation or unlock dependency.

AOP Scenarios sections: (1) five KPIs and funding bar; (2) scenarios and five funding cards in a row, advanced configuration below, custom save and exports; (3) Funding Prioritization Gate with one evidence gate and five funding stages; (4) Merit Score Framework, collapsed by default; (5) Demand Prioritized, open by default with multi-select BUR, Platform and Priority filters; (6) Demand Not Funded, open by default; (7) decision log, source data and rules, collapsed by default.

EW/BU: six stream-wide KPIs; cascading organisation, platform, demand type, area and status multi-checkbox filters plus search; full-width bubble plot; grouped editable table. OR within field, AND across fields, left-to-right option availability. Retain selected zero-match choices. Filters affect chart/table/export, never funding. Show stream versus filtered totals clearly. Overview uses the same display but no financial edits.

All demand tables open collapsed at BURF level. Each BURF summary reports child and funded counts, representative band, average merit across scored children, summed requested/prioritised/unfunded amounts, summed numeric benefits and evidence count. Expanding a BURF reveals program rows and edit controls where permitted. Opening, closing, Expand all and Close all are view actions only and create no decision event. Keep the first column and its header aligned and sticky during vertical and horizontal scrolling.

Inline program/group checkboxes and amount inputs commit directly, with auto-log, optional note, evidence review and return-to-automatic. Only program name opens a compact read-only popup of nonblank source fields, preserving real zeros. Retain scroll position. Show exact source lineage and missing-evidence warnings. Chart hover is informational.

Use original request on logarithmic y, merit on x and requested-demand bubble area. Missing/nonpositive requests remain in the table and are counted outside the chart. Enterprise Wide, BU Led and Overview show two distinct references: actual median merit for the plotted rows and the configured merit threshold. With no plotted programs, show no median line. Mouse hover and keyboard focus reveal ID, program, BURF, request, final amount, benefit evidence, score, stage and funding status. The merit threshold is not a funding promise. EW and BU Led edits are available independently and update the same scenario without checkpoint controls. Save custom, export portable, refresh preview, finalise, and fork must all operate on the same scenario.
