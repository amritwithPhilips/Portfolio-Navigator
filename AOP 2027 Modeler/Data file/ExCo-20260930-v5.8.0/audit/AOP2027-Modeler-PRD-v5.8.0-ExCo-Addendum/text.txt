AOP 2027 ExCo view product requirements  
Version 5.8.0 addendum. This specification adds the leadership decision view to the six-tab portfolio modeler. 
It supplements AOP2027-Modeler-PRD-v5.7.0.docx; the earlier document remains the specification for 
unchanged detailed workflows. The v5.7.0 HTML and both source workbooks are preserved. 
Product outcome 
ExCo can assess company IT cost, inspect accountable Programs, compare a recommended scenario and 
preview funding decisions in one concise view. Portfolio analysts can open the existing six tabs to change 
advanced configurations and review source evidence. Both views share one scenario and finance ledger. 
Meeting journey 
Company position 
Five KPIs show total IT, base Programs, budget headroom or excess, funded Programs and unallocated cost. 
Priority funding and receiving organisation costs explain the company position. 
My portfolio 
Select one of 16 ExCo leaders to inspect accountable Programs. Keep hard and soft submitted lifetime benefit 
claims separate. Open a Programs ID for source evidence. 
Compare options 
Compare baseline, recommended and current funding. Show the Programs that change from the current 
scenario to the recommendation. Save the current scenario before creating a recommended child draft. 
Decisions 
Preview a selected leader and stream trade-off, or a discretionary Programs scope decision with rationale. 
Review exact cost changes before applying. Save and export the meeting outcome.

Recommendation and finance contract 
Retain the default €100M Optimal scenario as the decision baseline. It is the best of 135 tested lever 
configurations under an objective that protects baseline-funded LFR and confirmed carry-over, retains at least 
€20.609M Sustain and maximises funding-weighted source merit. This is a finite scenario search, not proof of a 
global company optimum. 
Recommended base Programs funding is €99.963M: LFR €43.776M, confirmed carry-over €16.773M, Sustain 
€20.609M and Value €18.805M. PMI adds €5.19M and Operations adds €470.314463039M, producing total IT 
cost of €575.467463039M. Default tolerance is zero; source merit floor 45 and weights 40/25/15/10/10 are 
retained. 
BU row 276 Enterprise-wide charging is a percentage key only; its €40M is excluded from demand. Apply the 
approved 1,000× fraction correction and retain 22.6303317536% of EW unallocated. Optimal has 
€11.250895735M EW unallocated and €1.822M other BU unallocated. PMI has no BU charge. Operations own, 
Region and Function contributions are counted once. 
Confirmed carry-over funding uses the lesser of the requested amount and approved baseline cap. No carry-
over ROI threshold is introduced. Validated benefit evidence remains eligible; lifetime claims are not presented 
as annual savings. Nine missing-request and four uninterpretable-decision rows remain audit-only. 
Decision integrity 
Preview computes a proposed copy. Apply requires unchanged scenario ID, revision and source hash. Finalised 
scenarios block edits; a working version retains lineage. Manual decisions can exceed the budget and the 
excess remains explicit. Operations costs remain fixed to the source allocation. 
The recommendation is bound to the Programs source hash. A different source requires a new 
recommendation analysis. The offline Finalised status is a local lock, not a central approval signature. Export 
the full evidence workbook and save the scenario for recovery.

Release acceptance and limitations 
The release must pass 32 scenarios across six tabs, ExCo finance parity, actual configuration controls, 16 leader 
filters, decision preview and cancellation, undo, save and reload, finalise and fork, portable recovery, source 
refresh holds and source-linked Excel exports. An independent source replay validates 69,280 record fields, 
receiving organisation totals and Operations components. 
Funding, scoring and finance results must match v5.7.0 for the same valid inputs. The only engine validation 
enhancement rejects invalid imported request and merit reviews. No approved finance or prioritisation rule is 
changed. The final validation report records actual assertion totals and evidence. 
Implementation architecture 
The ExCo extension reads the existing scenario result through AOPApp. Commands delegate to the existing 
transaction, trade-off, undo, save and export functions. A state-change event refreshes the ExCo presentation. 
The detailed six-tab workbench remains available without a separate calculation model. 
Known decision gaps 
The source does not provide a quantified dependency and delivery-capacity optimisation model. Submitted 
benefits can overlap and do not establish realised cash flows. €180.0599M of base request remains unfunded 
under the recommended rules. Receiving allocation retains €0.465M for Bu-06 without a percentage and 
€1.357M explicit indirect unallocated cost. These balances remain visible until a source decision changes them.
