AOP 2027 · v5.9.2 PRD and Requirements

Date: 3 October 2026 · Base: v5.9.1 · Build: AOP2027-IT-Portfolio-Scenario-Modelling-v5.9.2.html (12 MB)

This document covers the two changes in v5.9.2: file size optimisation and the cost allocation drill-down feature on Tab 6. All prior v5.9.1 functionality, data, and ExCo features are preserved. Source finance allocation rules, engine version (5.8_1), and all 443 programs remain unchanged.

Conference-ready. File reduced from 38 MB to 12 MB. All 6 tabs, all exports, scenario save/load, and finance reconciliation verified at 578.5 M€ grand total. Zero console errors.

1. Product Requirements (PRD)

1.1 File Size Optimisation

IDRequirement
SIZE-01Operations source data compaction
Strip the 9 parsed Excel sheets (1,201 rows, 98,908 formulas, 21.3 MB) from operations-source-data. Retain the base64-encoded original workbook (3.6 MB) so the "Download original operations workbook" button continues to function. The runtime reads ops-data (103 KB) exclusively for calculations.
SIZE-02Demand formula removal
Strip 84,131 cell-level formula strings from the 5 parsed sheets in source-data (saving 6.4 MB). Cell values (rows), sheet structure, and the original base64 workbook must be preserved. The normalize() function reads cell values only. Formula text is recoverable from the embedded Excel binary at any time.
SIZE-03Zero functional regression
All 6 tabs, all engine calculations (scoring, allocation, levers, trade-offs, finance reconciliation), all exports (Excel, JSON, CSV, source XLSX), scenario save/load/validate, and the operations workbook download must remain fully functional. Session JSON round-trip validation must pass.

1.2 Cost Allocation Drill-Down

IDRequirement
DRILL-01Clickable allocation cells
Every numeric cell in the Organisation IT Cost Allocation table on Tab 6 must be clickable: BU Led (M€), Functions & Regions (M€), Operations Cost (M€), and Total IT Charge (M€). Each cell must carry data-col and data-recipient attributes for the click handler.
DRILL-02Detail panel rendering
Clicking a cell must open a detail panel below the allocation table showing the programs and/or operations that constitute the charge. The panel must be empty by default. Clicking a different cell must replace the panel content. A close button (✕) must dismiss the panel and remove the active cell highlight.
DRILL-03Programs detail — aggregated by program ID
Sub-org allocation splits within the same BU cluster must be summed into one row per program. A Type I program with 3 sub-org fractions (e.g., G&B + OHC + MCC all mapping to Personal Health) must appear as a single row with the aggregated cost and 100% of Program. The detail must not show raw finance ledger entries.
DRILL-04Programs detail columns
The programs table must show 9 columns: Type (badge), ID, Program Name, Organisation, Requested M€, Funded M€, [Cluster] Cost M€ (dynamic header naming the recipient cluster), % of Program (aggregated cost ÷ funded), and % of Org Cost (aggregated cost ÷ column total).
DRILL-05% of Program calculation
% of Program = (sum of all ledger amounts for this program to this cluster) ÷ (program funded amount) × 100. For Type I (Single BU): must be 100% (entire funded amount charged to one cluster). For Type II (Cross BU): must reflect the source allocation split. For Enterprise Wide: must reflect the EW charging key share. Display as integer percentage.
DRILL-06% of Org Cost calculation
% of Org Cost = (program's aggregated cost to this cluster) ÷ (total column cost for this cluster) × 100. Display to 1 decimal place.
DRILL-07Operations detail
When clicking Operations Cost or Total IT Charge, show the 3 operations ledger entries: Own Consumption, Regions Allocated, Functions & CoEs Allocated with amount and % of Ops Total. Use green type badges.
DRILL-08Total IT Charge combined view
When clicking the Total IT Charge column, the detail panel must show both Programs and Operations sections, each with their own sub-header, table, and totals.
DRILL-09F&R distributed row
The italic "Functions / Regions (distributed via Type II keys)" row must be clickable on its BU Led and Total cells. Clicking must show programs from the Unallocated recipient with indirect, other, and ew buckets. The panel header must read "Functions / Regions (distributed via Type II keys) — Distributed Demand Detail".
DRILL-10Filter bar
The programs detail must include a filter bar with 4 dropdown controls and a Reset button:
• Type: All Types / Type I - Single BU / Type II - Cross BU / Type III - Enterprise wide / Indirect Cross BU
• Organisation: All Organisations + each unique source org (up to 27)
• % of Program: 100% only / ≥ 50% / ≥ 25% / ≥ 10%
• % of Org Cost: ≥ 10% / ≥ 5% / ≥ 1%
The "100% only" option must use a ±0.5% tolerance to accommodate source rounding. The header row ("▶ Programs (N programs — X.X M€)") must dynamically update to show filtered count and filtered total.
DRILL-11Active cell highlight
The currently selected allocation cell must receive a visible highlight (blue background, blue bottom border). Only one cell may be highlighted at a time. Closing the panel must remove the highlight.
DRILL-12Dynamic column header
The cost column header must name the recipient cluster (e.g., "Precision Diagnosis Cost M€", "Personal Health Cost M€"). For the F&R distributed row, use "Distributed Cost M€".
