ExCo decision workspace requirements

What changed

The ExCo view now supports leader-specific Programs decisions, a Demand / Hard Benefits chart toggle, additional funding previews and custom columns from normalized and original source data. It shares the same scenario as the six-tab workbench. v5.7.0, v5.8.0 and both source workbooks are preserved.

  1. Decisions: select an ExCo leader, adjust inclusion or review request, merit and funded scope. Use Company funding settings for the same budget, levers and scoring configuration available in tab 2.
  2. Funding opportunities: enter an additional budget and rationale, choose both streams or F&R/BU Led, preview the added Programs and recipient costs, then apply or cancel.
  3. Customize columns: search and select scenario or original EW/BU source fields. Choices are stored per leader in the saved scenario. Fork and portable scenario recovery retain them.
  4. Synchronization: edits made in ExCo appear in the workbench, and workbench edits appear in ExCo. ExCo leader filters synchronize across Programs views. Charts and leader filters do not independently change funding.

Acceptance contract

IDCapabilityRequirement
EXCO59-01Leader decisionsExpose inclusion, exclusion, automatic funding, partial scope, request and merit review for all base Programs priorities. Keep PMI separate. Preview changes with rationale; persist through the shared scenario transaction.
EXCO59-02Company controlsExpose budget, tolerance, merit floor, five score weights, four editable lever bases/amounts and optional IT Simplification. Label these settings company-wide and preview before apply.
EXCO59-03Decision chartToggle requested Demand and quantified Hard Benefits against merit. Use log(1 + amount), request-scaled bubbles and funding status. Support mouse and keyboard source detail access.
EXCO59-04Additional fundingAccept a positive additional company envelope, one leader, optional stream and rationale. Select eligible whole remaining scopes in priority-stage then merit order. Respect confirmed carry caps and explicit manual exclusions. Preview additions, budget, headroom and recipient costs.
EXCO59-05Retained allocationsKeep existing funding unchanged when applying additional funding. Record retained automatic decisions as explicit overrides. Allow previewed return of these retained decisions to automatic; undo restores the whole additional-funding transaction.
EXCO59-06Benefit evidenceSeparate newly funded productivity, revenue and soft lifetime claims. Label productivity as a savings proxy. Do not infer annual savings, realised returns or incremental benefits for already funded partial scopes.
EXCO59-07Custom columnsOffer normalized scenario fields and original EW/BU source columns. Keep Programs ID/name/source access mandatory. Save column choices per leader in the scenario; retain them through save/reload, portable export and fork.
EXCO59-08Synchronized selectionSynchronize ExCo leader selections with the Programs filters in tabs 2–4 and One Portfolio. Support multiple leaders selected in the workbench. All six views and exports use the same funding and finance result; Operations recipient costs remain company-wide.
EXCO59-09State and validationGuard decision previews against a changed scenario ID, revision or source hash. Lock edits on finalised scenarios. Preserve earlier HTML builds and both source workbooks; validate source-linked Programs and recipient ledgers.
