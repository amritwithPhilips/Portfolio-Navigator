Key findings and remaining gaps

  1. EW residual is intentional. Preserve 22.6303317536% unallocated, equal to €11.250895735M in Optimal. This is the approved allocation treatment, not a failed reconciliation.
  2. Other BU residual is €1.822M. It includes €1.357M explicit indirect unallocated cost and €0.465M from Bu-06 without a recipient percentage. These remain visible; the model does not invent a recipient split.
  3. Funding choice remains material. €180.0599M of base requested demand is unfunded. This is not all eligible backlog: confirmed carry-over caps, source decisions, merit and whole-Programs fitting affect it. LFR bucket demand is €53.136M; €43.776M verified funding leaves €9.36M outside the default allocation.
  4. More budget alone does not solve coverage. The €350M stress scenario funds €149.604M base under the retained rules. The zero-budget test still has €475.504463M total IT from Operations plus separately funded PMI.
  5. Manual and tolerance excess is explicit. Scenario 07 funds €100.413M after manual decisions. A 5% tolerance funds €104.990M automatically. Neither should be described as a strict €100M outcome.
  6. Merit sensitivity is uneven. Floors 0 and 65 produce the same baseline funding; floor 100 reduces it to €81.158M. Increasing the payback weight funds €86.298M. These are policy sensitivities, not calculation defects.
  7. Benefit claims remain accepted for prioritisation. Optimal funded base Programs carry €5,153.663M hard and €7,574.797M soft submitted lifetime claims, kept separate. One hard claim represents 24.25% of funded hard claims. Validation of input does not establish additive or realised cash benefit.
  8. Source exclusions remain auditable. Nine missing-request and four uninterpretable-decision rows are excluded from active demand and retained in the source audit. There are 433 active Programs including PMI. No new source refresh was inferred; both supplied workbook hashes match the v5.7.0 build.
  9. Offline meeting workflow has limits. Finalised is a local scenario lock, not an electronic approval or centrally authenticated sign-off. Save and export decision evidence for recovery. Browser checks cover desktop Chrome at 1366–1920px; mobile, other browsers, concurrent multi-user editing and Excel recalculation in the desktop application are outside this suite.
  10. Import guard strengthened in v5.8.0. Imported request and merit reviews now enforce the same amount/range/rationale boundaries as live edits. This does not change valid scenario calculation results.
