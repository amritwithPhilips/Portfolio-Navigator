Why this was hard — complexity under the surface

Data stitching across 4 live sources

  • Live SharePoint Excel demand workbook (442 programs, 5 parsed sheets)
  • Separate Bill of IT operations workbook (182 services, 470 M€)
  • ExCo hierarchy mapping (16 leaders × 35 orgs with fuzzy match)
  • 67 individual ExCo LFR opt-in/opt-out decisions embedded as override rules
  • Enterprise-wide charging key (Type II BU allocation percentages)
  • 3 data refreshes during development — each requiring full audit trail
  • Benefit data repair: 158 null-benefit programs patched from authoritative extract

Multi-phase solver engine

  • 4-priority funding waterfall: LFR → Carry-Over → Sustain → Value
  • 5-component merit scoring with hybrid benefit (quantitative → qualitative fallback)
  • Balanced Investment: 9-phase engine (CCB 70%, ISC fill, STO fill, stream cap, region rebalance, bucket fill, hard benefit maximiser)
  • Per-leader trade-off cockpit: include/exclude by merit rank, budget delta, benefit impact
  • Lever cascade: changing any upstream lever auto-rebalances all downstream
  • Session management: save/load/fork with full decision audit trail
  • Financial reconciliation: Programs + Operations = Total IT AOP, validated to 3 decimal places

All in one self-contained HTML file

  • Zero server dependencies — open from desktop, SharePoint, or email attachment
  • 6 interactive tabs with real-time recalculation on every lever change
  • Embedded 11 MB of financial data (demand + operations + services + allocations)
  • Full Excel export (8-tab workbook generated in-browser with XLSX writer)
  • IndexedDB persistence: scenarios survive browser close, portable JSON export
  • Cost allocation drill-down: every cell clickable across 7 BU clusters
  • Optimised from 38 MB to 12 MB without losing any functionality
What started as a prototype to replace a static Excel model was transformed by CIO feedback into the One Portfolio Navigator through 43 build iterations in 18 days — a pace no COTS tool or consultancy could match. It stitches together live demand data, operations Bill of IT, ExCo hierarchies, and 67 individual leadership decisions into a single self-contained HTML file that models 578.5 M€ of IT investment. Estimated saving vs standard tooling: 0.8–1.5 M€ in year one and 8–11 months faster time to value.
